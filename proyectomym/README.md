# M&M by Ecléctica - Plataforma Web

Bienvenidos al repositorio oficial de **M&M by Ecléctica**, una plataforma web moderna, elegante y de alto rendimiento diseñada exclusivamente para reflejar la excelencia y la experiencia de más de 18 años en la producción de eventos de lujo.

## 🌟 Resumen del Proyecto

Este proyecto consiste en el desarrollo de una web premium, diseñada para captar la atención de clientes exclusivos y presentar los servicios de producción integral de eventos que ofrece la empresa. El diseño se centra en ofrecer una experiencia visual inmersiva, a la altura de los eventos que organiza M&M by Ecléctica.

## 📁 Estructura del Repositorio

- `/proyectomym`: Contiene todo el código fuente de la aplicación web.
- `M&M by Ecléctica.pdf.pdf`: Documentación de presentación oficial de la empresa.

## 🚀 Tecnologías Utilizadas

La plataforma ha sido construida utilizando tecnologías de vanguardia para asegurar la máxima velocidad, interactividad y un posicionamiento óptimo:

- **React 19**: Biblioteca líder para la construcción de interfaces de usuario interactivas.
- **Vite**: Herramienta de construcción ultrarrápida para una experiencia de desarrollo y carga optimizada.
- **Framer Motion**: Librería de animaciones que dota al sitio de movimientos fluidos y profesionales.
- **Lucide React**: Colección de íconos modernos y consistentes.
- **CSS3 Moderno**: Implementación de estilos personalizados de alta gama, incluyendo animaciones, cursores personalizados e interacciones avanzadas.

## 🛠️ Cómo Ejecutar el Proyecto (Para el Equipo de Desarrollo)

Si deseas visualizar el proyecto localmente, sigue estos pasos:

1. Asegúrate de tener instalado [Node.js](https://nodejs.org/).
2. Abre la terminal en la carpeta del proyecto web (`cd proyectomym`).
3. Instala las dependencias necesarias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
5. Abre el enlace que aparecerá en la terminal (usualmente `http://localhost:5173`) en tu navegador web.

## ✨ Características Principales

- **Diseño Inmersivo y Premium:** Paleta de colores elegante, tipografía sofisticada y animaciones fluidas (Scroll reveals, cursores personalizados, botones interactivos).
- **Video Reel Integrado:** Sección dedicada para mostrar de manera visual la calidad de los eventos producidos.
- **Optimización de Conversión (CTA):** Botón flotante de WhatsApp y múltiples llamados a la acción estratégicamente ubicados para facilitar el contacto directo.
- **Responsividad Total:** Diseño adaptable que ofrece una experiencia perfecta en dispositivos móviles, tablets y computadoras de escritorio.
